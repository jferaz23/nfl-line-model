Put Pro Football Reference season tables here (one file per season), e.g. for 2021-2025:
  games_2021.html ... games_2025.html   (browser: File > Save Page As on /years/<season>/games.htm)
or games_2021.csv ... games_2025.csv    ("Share & Export" > "Get table as CSV", pasted into a text file)
PFR does not allow automated downloading, so the pipeline only reads files you save yourself.
